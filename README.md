# 🤖 JASMINE AI

JASMINE AI adalah chatbot AI berbasis web yang dirancang sebagai teman ngobrol yang cerdas dan interaktif. Project ini dibangun menggunakan React untuk frontend, FastAPI untuk backend, MySQL sebagai database, dan Gemini API sebagai AI Engine.

---

## 🎯 Tujuan Project

Membangun aplikasi chatbot AI yang memiliki fitur:
- Login & Register
- Chat dengan AI
- Riwayat Percakapan
- Manajemen Profil
- Pengaturan Akun
- Dark Mode

---

## 🛠 Tech Stack

### Frontend
- React.js
- Vite
- Tailwind CSS
- React Router
- Axios

### Backend
- FastAPI
- SQLAlchemy
- Pydantic
- JWT Authentication

### Database
- MySQL

### AI
- Gemini API
